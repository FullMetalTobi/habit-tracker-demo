# Übungsheft: Seminar Spec-Driven Development mit KI-Coding-Agenten

Dieser Branch enthält nur das Übungsheft, nicht die App.

- `uebungen/uebungsheft-sdd-seminar.pdf`: Gesamtheft mit allen Übungen
- `uebungen/ue0-…pdf` bis `uebungen/ue7-…pdf`: einzelne Blätter
- `uebungen/uebungsblaetter-markdown.zip`: alle Blätter als Markdown. Befehle am besten von dort kopieren, die Einrückung bleibt erhalten.

Die App und die Stufen-Branches liegen auf `main` bzw. `stufe/*`, siehe `KURS.md` dort.
